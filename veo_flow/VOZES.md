# Vozes do Flow — base de conhecimento

> Motivo (Piter, 04/08): *"muitas aqui são péssimas"*. A lista do Flow é grande e a
> qualidade varia MUITO. Aqui ficam só as testadas, pra não perder tempo ouvindo tudo
> de novo a cada canal novo.

Onde aparece: Personagem → **Selecionar uma voz** → modal "Selecione a voz". Cada
entrada traz gênero, timbre e pitch. O modal tem "Exemplo de diálogo" (até 120 chars)
para ouvir antes de decidir, e "Personalizar a performance (opcional)".
